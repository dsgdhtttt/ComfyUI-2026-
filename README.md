课程一开始没有直接堆节点，而是先讲 AI 漫剧的基本构成。一部漫剧短片通常包括选题与剧本、分镜拆解、角色设定、场景与画面生成、动画化处理、配音配乐、剪辑合成和发布复盘。导师反复强调，ComfyUI 只是生产工具，真正决定作品能不能看的是前面的故事和分镜。零基础学员如果一上来就追求复杂画面，很容易做出一堆漂亮但接不上的图。课程要求先做 30 秒到 1 分钟的完整小故事，把流程走通，再谈风格和精度。

ComfyUI 入门部分讲得很务实。课程没有让学员死记节点名称，而是先理解几类核心环节：输入与提示组织、模型加载、图像生成、图像处理、一致性控制和输出保存。导师用“工作流”的方式讲节点连接，让学员明白每一步在解决什么问题，而不是照抄别人的节点图。零基础最怕的是“能跑但不知道为什么”，课程通过小练习让学员自己调整参数、替换素材、观察结果变化，逐步建立对生成过程的感觉。

角色一致性是漫剧动画的关键难点，也是课程重点。课程从角色设定表开始，要求学员先固定角色的外貌特征、服装、配色和性格表达，再进入画面生成。接着讲如何在不同场景中保持角色稳定：参考图怎么用、提示怎么组织、构图和角度变化时如何减少崩坏、哪些镜头需要重点检查。课程还提醒学员建立自己的素材库，把通过测试的角色图、场景图和风格参考整理好，避免每次从头试。对零基础来说，一致性不是靠某个神奇设置，而是靠设定、参考、筛选和复盘一起保证。

动画化部分课程没有一上来讲复杂运动，而是先区分“漫剧动画”的几种常见做法：轻微镜头运动、局部元素动效、角色表情与口型变化、场景转场等。不同做法对画面稳定性和制作成本要求不同。课程带着学员从简单动效开始，先让画面“活”起来，再逐步增加角色动作和镜头变化。导师特别强调节奏：漫剧不是动画电影，观众更在意故事推进和情绪表达，动效要服务叙事，不能为了动而动。

配音、音效和剪辑是让作品成立的另一半。课程讲了配音情绪与画面节奏的匹配、背景音乐的选择、音效的补充和字幕处理。很多零基础学员容易忽略声音，结果画面不错但整体很平。课程要求学员在剪辑时反复检查：信息是否清楚、转场是否自然、情绪是否有起伏、结尾是否收得住。最终作品不求长，但要求完整。
